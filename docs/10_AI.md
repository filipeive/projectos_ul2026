## Funcionalidades de IA Implementadas

### 1. AI Advisor — Gerador de Ideias (Portal)
- **Endpoint:** `POST /ai/generate-idea`
- **Input:** Interesses do estudante (texto livre)
- **Output:** JSON com `nome_projeto`, `problema_local`, `tecnologias[]`, `conceito`
- **Proteção:** Limite de tokens, sanitização de input

### 2. Kanban Creator — Sugestão de Tarefas (Workspace)
- **Endpoint:** `POST /ai/suggest-tasks`
- **Input:** Descrição do projeto + tarefas atuais do Kanban
- **Output:** Array de 3 tarefas sugeridas com título e descrição
- **Comportamento:** Inseridas automaticamente com flag `created_by_ai = true` e ícone ✨

### 3. Análise de Clima do Chat
- **Endpoint:** `POST /ai/analyze-chat`
- **Input:** Últimas 15 mensagens do chat (sem as do utilizador atual para evitar prompt injection)
- **Output:** Resumo de 3 frases: clima geral, dúvidas pendentes, recomendação pedagógica
- **Acesso:** Exclusivo para Docente/Supervisor

### 4. Resumo de Progresso Semanal
- **Endpoint:** `POST /ai/summarize-progress`
- **Input:** Estatísticas das tarefas Kanban + volume de mensagens
- **Output:** Parágrafo motivacional de progresso

### 5. Copiloto de Chat (Assistente Direto)
- **Para Estudantes:** Resposta pública à dúvida no chat
- **Para Docentes:** Sugestão privada de resposta (docente valida antes de enviar)
- **Endpoint:** `POST /ai/assistant-reply`

### 6. Piloto Automático (Auto-Reply)
- **Ativação:** Toggle pelo Docente no painel do Workspace
- **Comportamento:** IA responde automaticamente a dúvidas simples dos estudantes quando o docente está ausente
- **Endpoint:** `POST /ai/auto-reply`

## Segurança e Proteções

| Proteção                    | Implementação                                  |
|-----------------------------|------------------------------------------------|
| Prompt Injection            | Sanitização do input antes de enviar à API     |
| Limite de Tokens            | `max_tokens: 500` em todos os pedidos         |
| Rate Limiting               | Middleware do Laravel (throttle)               |
| Soberania Pedagógica        | Docente revê sugestão antes de enviar          |
| Custo de API                | Monitorizar via dashboard do OpenRouter        |
